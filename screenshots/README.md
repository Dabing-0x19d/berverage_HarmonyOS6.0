# Screenshots 目录

本目录用于存放应用演示截图。**开源仓库本身不包含真机截图**（真机截图通常含真实账号、消费记录等隐私），由贡献者按下方规范准备后通过 PR 添加。

## 数据脱敏要求

**所有截图必须使用演示数据**，不得包含真实用户信息或真实商业品牌：

- ❌ 真实手机号、unionId、头像、昵称
- ❌ 真实消费记录
- ❌ 真实店铺名（如"星巴克""瑞幸""Manner"等商业品牌）
- ❌ 真实饮品名（含版权商标的商品名）
- ❌ 真实价格
- ✅ 演示店铺：`演示店铺 A`、`演示店铺 B`、`演示店铺 C`
- ✅ 演示饮品：`示例咖啡`、`示例拿铁`、`示例奶茶`
- ✅ 演示价格：`¥15`、`¥20`、`¥25`
- ✅ 演示日期：使用相对日期（如"今天""昨天"）

## 截屏方法

HarmonyOS 真机：
- `音量下 + 电源` 截屏

DevEco Studio 模拟器：
- 右侧工具栏的相机图标 → Save Screenshot
